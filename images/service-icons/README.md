# Иллюстрации для карточек услуг

Загрузите сюда пять оптимизированных файлов WebP (названия нужно сохранить точно):

- `remont-okon.webp` — ремонт и регулировка окон (шуруповёрт, шестигранник)
- `okna-pvh.webp` — окно ПВХ
- `balkony.webp` — остеклённый балкон
- `alyuminievye-konstrukcii.webp` — алюминиевые раздвижные конструкции
- `osteklenie-verand.webp` — остеклённая веранда

При загрузке изображений сайт автоматически переключится с резервных контурных иконок на нарисованные иллюстрации, без удаления старых элементов.
